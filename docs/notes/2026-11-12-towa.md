# The project is named towa

Date: 2026-11-12

`acpharness` is renamed `towa`, after the Towa Organization of Boogiepop Phantom. One word now names everything:

- the binary and `cmd/towa`
- the Go module, `github.com/gfx-labs/towa`, and the two tool modules under it
- the config and state directories: `/etc/towa`, `~/.config/towa`, `~/.local/state/towa`
- the `TOWA_` environment prefix, so `TOWA_CONFIG` and `TOWA_LIMITS__MAX_WALL`
- the `towa` key under `_meta` and in error data (`pkg/acp/harness.Key`)
- what is sent to other parties: the user agent `towa/<version>`, the Codex `originator`, the MCP client name, the ACP agent name, the OTel service name and the `towa.` metric names

The binary was `acph` for an hour before this. That name is gone too.

Every tracked file was changed, the dated notes included, so that a search for the old name finds nothing to follow. One mention is kept: `docs/acpharness-needs.md` in the contracts note is a file in another repository.

The GitHub repository is renamed separately. GitHub redirects the old address, and the module path does not depend on a checkout's directory name.
