# Production runtime wiring, 2026-11-11

`serve` now constructs the real session runtime instead of `session.Stub`.
The process owns provider clients, the shared HTTP client, the directory store,
the MCP pool, child admission, and optional embeddings and Jev clients. Startup
runs the store's incomplete-directory sweep. Shutdown drains the session Host
before closing the MCP pool and provider clients, then stops telemetry.

Each attached session owns its MCP manager, frozen discovered tools, read
fingerprints, replay mapper, and compaction controller. The mapper is built
from the attached model's assembled tools after discovery, without rediscovering
MCP during replay. Its context-window lookup covers that configured chain.
Unknown historical models produce no estimated usage window. Full stored history
is still replayed, including entries before compaction and fork source entries.

Each prompt resolves the current configured model, context files and instructions.
The router carries the selected entry's context window, output allowance, exact
captured interruption text and role, and system blocks through fallback. Unknown
models and unavailable prompt or dialect captures fail explicitly. No default
model, prompt template or wire identity is guessed.

The session keeps semantic embedding history across prompts on the same
configured model. A configured-model change cancels the old controller and
creates a new one. Summary requests retain their own checkpoint prompt, and
their allowance is bounded by the smallest configured chain entry. Provider,
model and account origin checks apply before opaque history replay.

A subagent runner opens a runtime for the actual child turn, not the parent's
loop. It waits for the child turn to return before closing its manager with an
uncancelled cleanup context. Cleanup errors are joined with the run error without
discarding recorded usage. Partial setup closes the manager it created.

## Remaining acceptance

At this checkpoint, only the captured Codex dialect and its exact eleven catalog
model names have deployed prompt support. Claude and generic model-facing
constructors are pending their capture integration. The factory refuses them
rather than inventing tool schemas or prompt text. A successful production
factory turn must be recorded with its actual assembled request when that path
is available. Existing custom-tool loop recordings are not rewritten to stand
in for it. Real external provider credentials, native compaction, OAuth model
requests and macOS runtime behavior have not been exercised.
