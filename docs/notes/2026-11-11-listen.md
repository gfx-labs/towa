# Socket listeners

2026-11-11

`src/listen` opens a unix socket and a TCP listener and serves connections concurrently. It knows nothing of sessions or ACP framing. The handler receives `context.Context` and `net.Conn`. On TLS listeners the handshake has completed before the handler runs. The same newline-delimited JSON-RPC used by stdio goes over the socket.

## Config and CLI wiring

Stdio remains on by default. Socket listeners are off until their path or address is set. The config keys are:

| key | default | meaning |
|---|---|---|
| `listen.stdio` | `true` | CLI serves standard input and output |
| `listen.unix.path` | empty | absolute socket path, empty means off |
| `listen.unix.mode` | `"0600"` | octal permission bits, as a string |
| `listen.tcp.address` | empty | host:port, empty means off |
| `listen.tcp.plaintext_on_non_loopback` | `false` | explicitly permit plaintext outside loopback |
| `listen.max_connections` | `0` | maximum concurrent socket handlers, zero means unlimited |
| `listen.handshake_timeout_seconds` | `10` | TLS handshake bound, zero means none |

Both `listen.unix.tls` and `listen.tcp.tls` have `cert_file`, `key_file`, `client_ca_file` and `require_client_cert`. Empty certificate and key mean TLS is off. Otherwise both are required. A required client certificate needs a client CA. With a CA and an optional certificate, an absent certificate is accepted but a presented one must verify. TLS uses version 1.3 or newer. The handshake timeout default follows Go's `http.DefaultTransport.TLSHandshakeTimeout`, not a measurement of this agent.

A non-loopback address without TLS is refused unless `plaintext_on_non_loopback` is true. Loopback IP literals and `localhost` count as loopback. Other names are not resolved to decide whether they are safe. An empty host binds every interface and requires TLS or the explicit plaintext key. `Open` validates even when called directly, not through the config loader.

No new flags are needed: the existing `--set` accepts these keys. For example:

```
acpharness --set listen.stdio=false --set listen.unix.path=/run/user/1000/acpharness.sock serve
```

The session worker agreed this call:

```go
err = listen.Serve(ctx, cfg.Listen, func(ctx context.Context, conn net.Conn) error {
    return host.ServeConn(ctx, conn)
}, logger)
```

The CLI creates `session.NewHost(session.Options{...})` once and uses that host for stdio and every socket connection. Each `ServeConn` creates its own Agent. The process host, not this package, owns the shared provider HTTP pool, auth store and session store. The listener package does not read credentials.

For startup errors before any handler starts, use `listeners, err := listen.Open(ctx, cfg.Listen, logger)`, check the error, then call `listeners.Serve(ctx, handler)`. `listeners.Addrs()` reports bound addresses, including the actual port for `:0`. Call `Close` if abandoning a successful Open before Serve. No socket listener configured is `ErrNoListener`, not a stdio implementation. The CLI handles stdio itself and only calls this package when a socket is configured.

## Lifecycle

Before binding a unix path, the process holds a nonblocking flock on `<path>.lock`. A second cooperating process fails with `ErrInUse`. If a socket file already exists, a successful connection means a live listener and the file is left alone. Only `ECONNREFUSED` permits removal as stale. A non-socket, a symlink, a permission error, cancellation or another failure leaves the path alone. The parent directory must already exist and must be trusted. The lock coordinates instances of this package, not another program replacing paths in a writable directory.

The socket is chmodded before accepting. Between bind and chmod it has the umask's permissions, so use a private parent directory when access must be restricted from the moment of bind. This package does not change the process-wide umask or the parent's permissions.

On shutdown, accepting stops, handler contexts are cancelled, active sockets are closed to unblock reads and writes, and handlers are joined. Only then is the socket file removed and the flock released. The empty lock file stays, because unlinking a locked file would let later openers acquire a different inode. A handler must return after cancellation or closed I/O. No timer pretends a handler has stopped if it has not.

The optional connection cap covers handshakes and handlers across both sockets. A listener can hold one accepted connection waiting for a slot, then stops accepting until a slot is available. Further clients wait in the kernel queue. Slots are not reserved by listeners sitting idle in Accept, which would starve the other listener. Stdio is outside the socket cap.

A handshake or handler error ends only that connection and is logged with listener and peer address. An accept failure ends the listener process's Serve call and shuts down its other listeners. Context-requested shutdown returns nil.

## CLI transport helper

`src/cli/listen.go` defines:

```go
func serveListeners(ctx context.Context, cfg config.Listen, host *session.Host, h Host, logger *slog.Logger, closeStdio func() error) (result error)
```

The helper opens all configured sockets before starting stdio, then serves stdio, unix and TCP concurrently on the supplied host. In socket mode, stdio EOF retires stdio only. A stdio read/protocol error is logged and also retires stdio only. Without sockets, stdio's result ends the invocation. A socket accept failure ends all transports. After cancellation, the helper joins every transport before returning. The caller closes Host and the shared runtime resources afterwards.

`closeStdio` is an explicit ownership handoff, not an inferred `io.Closer` assertion on caller streams. Pass nil for borrowed streams. When supplied, it is called once on shutdown to close the invocation-owned input and output, so both reads and blocked response writes unblock. Its error is returned and its completion is joined. The CLI must supply the actual owned streams, never a hidden global descriptor. With no callback, writes must not block shutdown and an ACP reader can remain blocked until the reader ends or the process exits.

The helper tests use the real session Host, a stdio pipe and real unix/TCP listeners. They check all three serving concurrently, owned-stream cancellation including a client that does not read responses, borrowed streams left open, daemon survival after stdio EOF/error and stdio-only result propagation. Focused helper tests passed ten race runs, CLI vet passed, and darwin arm64 plus Linux CGO-disabled builds passed. CLI lint reported only the other lane's not-yet-wired `mcp_runtime.go` functions. Central `cli.go` wiring remains the coordinator's change.

## Certificates

Files are checked at Open and loaded again on each handshake with `GetConfigForClient`. A rotated server certificate or client CA applies to the next connection without restarting, while existing connections keep their established TLS state. A missing or inconsistent replacement causes that handshake to fail, not a fallback to the old certificate. Deploy complete certificate/key pairs together, for example by atomically replacing a directory symlink. There is no watcher or background reload goroutine.

## Tests and limits

Real unix sockets and TCP sockets, real ECDSA certificates generated in each test, and the repository ACP connection exercise:

- two clients connected and served on one unix socket;
- configured socket mode;
- TCP with TLS, plaintext refusal and an untrusted server CA;
- unix TLS with required and optional client certificates, including foreign certificates;
- rotation of the server certificate to another authority, and survival of an established connection;
- missing certificate files failing before bind;
- a stale socket being replaced and live sockets being preserved, both with and without this package's lock;
- preserving a regular file at the socket path;
- shutdown with a client open and with a handler blocked reading;
- half a JSON-RPC line followed by disconnect, then a successful next client;
- the configured connection cap.

The foreign-certificate test explicitly supplies `GetClientCertificate`: Go's default client selection omits a certificate whose issuer is not in the server's advertised CA list. Omitting it would test the optional-certificate path rather than rejection of a presented untrusted certificate.

`tools/conformance/TestSocketClients` drives the actual binary's unix and loopback TCP listeners with the coder ACP SDK. Two unix clients and one TCP client remain connected together, create separate sessions and receive explicit typed no-model request failures rather than Stub output. A prompt naming another connection's session is refused with `-32002`. One client's EOF leaves the other sessions usable. The daemon starts with stdio at EOF, so continued socket service checks the daemon EOF rule too. SIGTERM with two clients still open must close their streams, exit successfully and remove the unix socket file. Addresses come from structured startup logs, including the actual kernel-assigned TCP port. The earlier stdio bridge was removed. This test uses plaintext loopback TCP: real TLS and mTLS remain covered at the production listener package boundary, not through the SDK.

Initial listener checks before the runtime migration: race tests for `src/listen` and `src/config` passed five runs, scoped vet passed, and listener lint reported zero issues. Config lint also reported unrelated in-progress compaction/conversation-search files, which this lane did not edit. The full conformance module passed three race runs, vet and lint. `TestSocketClients` also passed ten times with an agent binary built using `go build -race`, so both processes were instrumented. The full CLI suite passed under the race detector. Darwin arm64 and Linux CGO-disabled builds passed for the listener/config packages and the CLI helper.

No macOS runtime was used. Darwin builds do not check runtime flock behavior, unix permissions or socket path limits. Keep paths short: the OS-specific unix sockaddr limit applies and bind errors are returned, with no truncation. No live login, real token store, provider request or key was used.
