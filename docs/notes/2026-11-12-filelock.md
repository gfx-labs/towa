# filelock: one package for advisory file locks

2026-11-12

`src/auth`, `src/store/dir` and `src/listen` each called `flock` directly, with their own EINTR loop, so none of them built for a target without `flock` (wasm). `src/filelock` holds `Lock` and `TryLock` with `Shared` and `Exclusive` modes. `flock_unix.go` (linux, darwin) calls `unix.Flock` and retries on EINTR. `flock_other.go` returns `errors.ErrUnsupported`, so a caller on another platform fails instead of running unlocked. `TryLock` wraps `ErrHeld` when the lock is taken, which callers match in place of `EWOULDBLOCK`.

A platform with another locking mechanism (a Durable Object, a lease) gets its own file in the package.

Behavior on Linux and macOS is unchanged. `src/store/dir`, `src/auth` and `src/listen` tests pass.
