# ACP package moves to go-acp

2026-11-13

`pkg/acp`, `pkg/acp/acptest`, the schema files and `tools/acpgen` moved
to `github.com/gfx-labs/go-acp` (public, Apache-2.0), with their history.
towa imports it as `acp "github.com/gfx-labs/go-acp"` and
`github.com/gfx-labs/go-acp/acptest`.

Why: the package is protocol code with nothing towa-specific, and other
programs use it: acpc (`github.com/gfx-labs/acpc`) as the client side,
protocol7's worker. Its own module keeps their dependency lists free of
towa's, and lets a schema change be tagged without a towa change.

- `pkg/acp/harness` holds towa's own `_meta.towa` types, so it stays and
  is now `pkg/harness`.
- The generator, its tests and lint, and the generated-code check run in
  go-acp's CI. towa's CI no longer runs them.
- The two commits made to `tools/acpgen` after the move started
  (`cb6241d`, `33527e5`) are in go-acp v0.1.1. The generated code is
  unchanged by them.

Dependency: `github.com/gfx-labs/go-acp` v0.1.1. It needs
`valyala/bytebufferpool`, which towa already had.
