# acpgen

Generates the `*_gen.go` files of `pkg/acp` from the ACP schema files in `pkg/acp/schema`.

```
go generate ./pkg/acp
```

That runs `go run . -schema ../../pkg/acp/schema -out ../../pkg/acp` in this directory. Both flags are required.

This is its own Go module, so its one dependency (`dave/jennifer`) stays out of the towa binary's module.

## Origin

Copied from `cmd/generate` in [coder/acp-go-sdk](https://github.com/coder/acp-go-sdk) at commit `492745b` (2026-11), Apache-2.0. `LICENSE` is the SDK's license file. Upstream's `internal/{emit,ir,load,util}` are `emit`, `ir`, `load` and `util` here.

## Changes from upstream

Each changed file says so in its first lines.

- Import paths point at this module. Generated files are headed `Code generated by tools/acpgen`.
- `main.go`: `-schema` and `-out` are required. The search for a repository root with a `schema/` directory is removed.
- `emit/types.go`, `emitValidateJen`: a Request, Response or Notification type that is an `anyOf` union gets a `Validate` that returns nil. Upstream read the parent's required properties off the union wrapper, which has no such fields, so schema 1.31.0's `CreateElicitationRequest` did not compile.
- `emit/types.go`, `emitValidateJen`: a required string is rejected when empty only if the schema gives it a `minLength`. Upstream rejected every empty required string, so writing an empty file (`fs/write_text_file` with `content: ""`) failed with `Invalid params`. `load/load.go` reads `minLength` for this.
- `emit/types.go`, union `MarshalJSON`: nothing is emitted after the `return` of a non-object variant. Upstream emitted the object path after it, which `go vet` reports as unreachable code (20 places with schema 1.31.0).
- `emit/dispatch.go`: the `session/prompt` and `session/cancel` cases have no cancellation code. Upstream called `registerPrompt` and `cancelPrompt` on the connection. Here the agent orders a cancel against a session's prompts with `acp.Arrival`.
- `emit/dispatch.go`: outbound request wrappers call `SendRequest[T](ctx, c.conn, method, params)`, context first.
- The generator and generated codecs use Go 1.27's `encoding/json/v2` and `encoding/json/jsontext`. Raw request parameters are `jsontext.Value`.
- Optional scalar, pointer and interface fields use `omitzero`. Optional collections use `omitempty`, and optional value structs remain present, matching the old encoder.
- Union and default codecs implement `MarshalJSONTo` and `UnmarshalJSONFrom`. An object variant is encoded straight from its struct, in the struct's member order, with HTML escaping. Collection defaults are filled explicitly rather than relying on the encoder's nil-collection options.
- `emit/union_codec.go` holds union selection and codec emission.
- `emit/constants.go`: the comment on `ProtocolVersionNumber` no longer calls this an SDK.

## Check

```
go vet ./... && go test ./...
```
